# 预测模型整改与晋级状态

更新时间：2026-08-06（北京时间）

## 已生效的整改

1. 每场只有一个 `primary_selection` 可作为核心方案和研究主成绩。
2. `directional_scenario` 及 `picks.had/picks.hhad` 降为联合净胜球诊断，不是两条推荐，不参与核心命中结算。
3. 看板六宫格只高亮唯一核心；联合格子只显示“情景”。
4. L0、市场克隆或缺乏独立数据的场次标记为 `market_baseline_only`，强制 C 不执行。
5. 足球层新增全场地小样本收缩和180天半衰期；同联赛赛果少于30场，或任一球队截止前少于5场时，独立足球权重强制为0。已导入8个常见联赛46,711场授权历史赛果。
6. 市场价格在融合层只使用一次；赔率拟合比分只作校准对照，不得冒充独立足球证据。
7. 机构层明确负债和真实投注量不可见，只解读风险调整后价格、去水与走势，不猜机构内部赔付。
8. 每日增加分布体检：极端联合情景占比达到80%或单一联合情景达到60%时报警并进入健康检查；只要求复核输入和校准，不为凑多样性篡改概率。

## 2026-08-05 赛后新增优化项

1. **修正 Directional 复盘口径（确定性程序缺陷，优先级高）**：当前复盘报告将 `reviews.strategy_correct` 同时当作 Primary 命中与“Directional 双中”展示。2026-08-05 奥胡斯 2:1 萨巴赫的实际联合结果是 `H/D`，锁定 `directional_scenario` 为 `H/H`，但报告误显示“双中”并计入100% Directional 命中率。应单独按 `directional_scenario == actual_joint` 计算联合诊断命中，`strategy_correct/primary_correct` 只服务唯一核心成绩；修正后重算历史报告。
2. **继续观察首回合与体能对一球边界的影响（候选经验，不晋级）**：奥胡斯场次赛前已识别加时负荷、萨巴赫低失球与首回合保守空间，实际落在主队净胜1球；但 `H/H` 与 `H/D` 赛前概率仅差约4.8个百分点，且该场为市场克隆样本。只累积分层样本，不因单场上调让平或小胜权重。
3. **保留短价热门的价格纪律（继续有效，不新增规则）**：费内巴切2:0的方向和净胜球诊断均命中，但赛前价格EV为负、首发和四机构轨迹未闭环，C级不执行仍是正确过程。不因“赛果对”放宽正EV压力测试或信息门槛。

## 晋级前置条件

- 建立严格赛前时间戳的多赛季球队攻防历史，包含主客场、对手强度、休息日、赛事类型和可用阵容。
- 使用严格 walk-forward，至少100场真正通过独立数据门槛的样本。
- HAD、HHAD、联合净胜球的 Brier 和 Log Loss 均不劣于去水市场基线，且至少一项有稳定样本外改善。
- 概率校准、分联赛表现和净胜球区间不得出现系统性塌缩。
- 在达标前，challenger 不得覆盖生产概率或生成投注票。
